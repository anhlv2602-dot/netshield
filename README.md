# NetShield — LAN DNS Ad-Blocker & Android Local VPN

Quản lý độc lập tại `/Users/anhlv2602/Apps/netshield` (kho GitHub Private `anhlv2602-dot/netshield`):

1. `netshield-dns/`: Máy chủ DNS chặn quảng cáo & mã độc toàn mạng LAN (`http://127.0.0.1:8080`, LaunchDaemon `com.local.netshield-dns`).
2. `netshield-android/`: Ứng dụng Android Local VPN chặn quảng cáo & mã độc (`v1.0.7` — hỗ trợ IPv4/IPv6, tối ưu pin TTL 300s, tự nghỉ khi kết nối mạng nội bộ `192.168.1.210`).
3. `netshield-extension/`: Tiện ích trình duyệt **NetShield Web** (`v1.0.2` — Manifest V3, ẩn mục *Được tài trợ* Facebook, bỏ qua quảng cáo YouTube, ẩn quảng cáo Zing MP3 / Spotify Web / báo Việt Nam).
