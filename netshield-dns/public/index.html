Hướng dẫn trỏ DNS cho toàn mạng LAN

Địa chỉ IP máy Mac Mini hiện tại:

Đang kiểm tra...
  1. Cố định IP cho Mac Mini trên Router/Modem (DHCP Reservation) để IP không bị đổi sau khi mất điện.
  2. Chạy NetShield DNS ở cổng chuẩn 53 bằng lệnh:
    sudo ./scripts/run-lan.sh (hoặc cài tự chạy 24/7: sudo ./scripts/install-launchd.sh)
  3. Vào phần DHCP Settings trên Router/Modem nhà mạng → đổi Primary DNS thành IP Mac Mini ở trên (xóa trống Secondary DNS hoặc điền chính IP Mac Mini).
  4. Ngắt kết nối Wi-Fi rồi kết nối lại trên điện thoại/laptop để nhận DNS mới.
