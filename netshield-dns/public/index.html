Giao diện mạng & IP máy chủ DNS
Đang kiểm tra...
  1. 1
    Cố định IP cho Mac Mini trên Router/Modem (DHCP Reservation) để IP không đổi sau khi mất điện.
  2. 2
    Chạy NetShield DNS ở cổng chuẩn 53: sudo ./scripts/run-lan.sh hoặc tự chạy 24/7: sudo ./scripts/install-launchd.sh
  3. 3
    Vào DHCP Settings trên Router/Modem → đổi Primary DNS thành IP được đánh dấu Khuyên dùng ở trên (để trống Secondary DNS hoặc điền cùng IP).
  4. 4
    Ngắt kết nối Wi-Fi rồi kết nối lại trên điện thoại/laptop để nhận DNS mới.
